Data Backup & Portability
How the Database works on GitHub Pages:

GitHub Pages only hosts static files, so traditional MySQL/PostgreSQL servers cannot run there. This suite uses Dexie.js (IndexedDB) which gives you a high-capacity, lightning-fast database running directly inside your browser. All data stays saved even when you close the tab or restart your computer.

Multi-device sync: Use the 1-click JSON export/import to transfer your data between devices, or connect free Firebase Firestore in seconds.
